Create tasks in seconds

A task is one focused change. Small tasks give the agents a clear target and produce better results.

Type it in the header

Use the What needs to be done? box at the top. Press Enter and the task appears in the Backlog — no forms, no setup.

Ask the Assistant

The dashboard Assistant (Ctrl/Cmd+Alt+A) can create and edit tasks for you. Describe the outcome and it takes care of the rest.

Pair with the agent

The Coding Agent tab is pinned to the tip of the main branch. It reads your latest code and can create and edit tasks through the bundled ajapopaja skill.

The agent workflow

A proven loop from idea to merged change. Run every step by hand, or let the bots hand off to each other.

1

Sharpen the spec with SpecBot

You don't need a perfect spec. Write a short description, then let SpecBot expand it.

SpecBot proposes an elaborated specification inline; you accept or reject it, and the accepted text becomes the task's spec.

2

Design with ArchBot

Tick design document when the change deserves a plan. ArchBot turns the spec into a structured design doc.

Design docs are versioned on every write — yours or the AI's — so you can always compare and roll back to an earlier revision.

3

Implement with CoderBot

Schedule the task and CoderBot implements it in an isolated sandbox and opens a pull request.

Tasks sent to CoderBot are queued and executed sequentially, so parallel requests never race on the same working copy.

4

Review with ReviewBot, then iterate

ReviewBot inspects the spec, the design doc and the diff, and stores a technical review on the task.

Use its findings to create the next tasks. Accept the pull request to land the change, then start the next iteration.

Choose which model each bot uses in the pipeline properties (Ctrl/Cmd+Shift+P or the edit icon next to the pipeline name) — e.g. a fast model for quick specs and a stronger model for implementation.

Your workbench

Four tools around the same repository, always one click away. Your selection and scroll position survive tab switches.

Task editor

Open any task to read and edit its spec and design doc. SpecBot and ArchBot assist right where you work, and you approve every change before it is used.

Coding Agent

An interactive session pinned to the tip of the main branch. Explore the code, ask questions, and create or edit tasks through the ajapopaja MCP skill.

File Browser

Browse the repository without a session and preview syntax-highlighted files. Use the filename search to jump straight to a file.

Commits

See the changes in the repository, newest first, and open any commit in an inline DiffView before you accept the change.

Bring your own agent

Everything the UI can do with tasks is also exposed over the Model Context Protocol.

ajapopaja MCP in the Coding Agent

The Coding Agent tab already speaks MCP through the bundled ajapopaja skill, so it can search, read, create and schedule tasks for this pipeline.

External coding agents

Point any MCP-capable agent (Claude, Cursor, VS Code, …) at the server and let it read and implement tasks from outside the dashboard. See the skill in .pi/skills/ajapopaja.
