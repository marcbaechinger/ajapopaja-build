Welcome to Ajapopaja Build

Build your first pipeline

Turn a Gitea repository into an autonomous, human-supervised workspace. Connect the repo, describe the work as tasks, and let the agents design, implement and review it — while you stay in control and approve every result.

New here? Follow the four steps below — it takes about five minutes.

How it works

1

Create a Gitea repository and credentials

Ajapopaja connects to your Gitea host over HTTPS. Create a repository, then generate an access token that lets Ajapopaja clone it and push changes back.

1a · Create the repository
  1. Sign in to Gitea and click + → New Repository.
  2. Name it, e.g. my-app, and choose public or private.
  3. Initialise it with a README so there is an initial commit to clone.
  4. Copy the HTTPS clone URL: https://git.example.com/you/my-app.git.
1b · Generate an access token
  1. Click your avatar → Settings → Applications.
  2. Under Manage Access Tokens click Generate New Token.
  3. Name it, e.g. ajapopaja-build.
  4. Grant the repository permission with Read and Write so Ajapopaja can clone and push.
  5. Also enable the issues permission (Read and Write) if you want task/issue integration.
  6. Generate the token and copy it — it is shown only once.
Keep the token secret. Ajapopaja stores it on the server and never sends it back to the browser.
2

Connect the repository to a new pipeline

Open the pipeline dialog and choose the Remote Repository tab. Enter the repository name, HTTPS clone URL, your Gitea username and the token from step 1.

No remote yet? You can also start with a local workspace path and connect Gitea later.

3

Break the work into tasks

Inside the pipeline click New Task and describe one unit of work. Add a title and a spec, and tick design document when the change needs a plan first.

Small, focused tasks produce better agent results than one giant task.

4

Let the agents implement and review

ArchBot drafts the design → you approve it → CoderBot implements it and opens a pull request → ReviewBot reviews the diff.

Everything lands back in the pipeline for your accept / reject decision.

Jump-start a new project

No code yet? Expand a blueprint, copy the prompt and paste it into the Assistant or the Interactive Coding Agent. It creates the ajapopaja tasks that scaffold the project layout and the build, lint, test and serve commands.

Ready-to-use ajapopaja task prompt 
Create ajapopaja tasks in this pipeline to bootstrap a brand-new React single-page application. Please create tasks in ajapopaja for each of the three steps below; use the ajapopaja task tools/skill and give every task a clear title and a detailed spec.

Task 1 — Set up the React single-page app blueprint
- Vite (latest) as the build tool and dev server
- TypeScript in strict mode
- React 18+ with function components and hooks
- React Router for client-side routing
- Tailwind CSS for styling
- Vitest + React Testing Library for tests
- ESLint + Prettier

Task 2 — Create the project layout (directories and files)
- Scaffold the app at the repository root
- Configure TypeScript strict mode, path aliases and the Vite dev proxy if needed
- Create a clean folder structure: src/components, src/pages, src/lib, src/styles

Task 3 — Set up the tooling and a basic smoke test app
- Configure the tooling for init/install, building, linting, testing and serving (HTTP) the stack
- Build a small but polished smoke test app (for example a task list with add / complete / delete) that exercises state, routing and reusable components and renders in the browser
- Deliver the exact commands for init/install, build, lint, test and serve (HTTP) so they can be pasted into the PipelineEditDialog's Build, Lint, Test and Serve configuration

Create these ajapopaja tasks now. Keep each task small and independently reviewable, and do not commit node_modules/ or dist/.
